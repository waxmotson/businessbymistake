# businessbymistake

All of the HSC Business Studies multiple choice questions.

## Setup

1. Put question images in `static/` named like:
   `HSC_BUSINESS_2025_Q01.png` … `HSC_BUSINESS_2016_Q20.png`
2. (Optional) Add `vine2.mp3` in the root for the click sound.
3. (Optional) Add `favicon.ico`.

## Files

- `index.html` — page
- `main.js` — question loading + answer checking
- `streak.js` — streak / personal best (localStorage)
- `answers.js` — answer key for 2016–2025
